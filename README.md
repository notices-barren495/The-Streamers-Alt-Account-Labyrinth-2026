## 🕹️ About

The Streamer's Alt Account Labyrinth is a dark adventure RPG set inside the secret online identities of the Rag Drops girl band. Explore hostile labyrinths, survive malicious monsters, uncover hidden truths, and hunt the owner of each alt account. This Windows build is an unfinished pre-release that surfaced ahead of schedule—raw, unstable, and not the final release.

For players who want story-driven dungeon exploration, psychological horror, mystery, and an unpolished underground dev-build atmosphere.
